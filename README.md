# JavaScript exercises

A practice copy of [The Odin Project's JavaScript exercises](https://github.com/TheOdinProject/javascript-exercises).

Most exercise files are still starter code. The included `solution/` directories come from the original curriculum.

## Run an exercise

With Node.js and npm installed:

```bash
npm ci
npm test -- 02_repeatString/repeatString.spec.js
```

Each numbered folder contains a task description, an implementation file, and Jest tests. Complete the implementation, then enable the skipped tests one at a time. Check the reference solution after solving the exercise.
